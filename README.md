# 个人学术主页（GitHub Pages）

北京工商大学本科生学术主页，含个人简介、教育经历、研究（金融科技与商业银行成本效率论文）、技能与联系方式。

## 本地预览

直接双击 `index.html` 即可在浏览器中预览。

## 部署到 GitHub Pages

1. 注册 GitHub 账号，创建仓库 `【用户名】.github.io`（用户名必须一致）；
2. 将本文件夹推送到该仓库的 main 分支；
3. 仓库 Settings → Pages → Source 选 "Deploy from a branch"，分支选 main / (root)，保存；
4. 稍等片刻，访问 `https://【用户名】.github.io` 即可。

## 使用前需替换的占位符

- 【姓名】、【学院/专业】、【年级】、【邮箱】、【用户名】等
- 论文摘要与核心发现（可按你的实证结果更新）
- 技能与课程列表
